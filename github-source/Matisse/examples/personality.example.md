# 自定义角色 / Your character

这是写作提纲，不是预设人格。首次运行会创建空白的 config/personality.md，
请在网页「设置 → 编辑角色设定」中写下自己的内容，或直接编辑这个文件。

可以考虑：

- 身份与称呼：角色如何称呼自己，如何称呼对话对象？
- 性格与价值观：有哪些稳定的特点、偏好和自己的见解？
- 说话方式：简洁还是细腻，是否使用动作描写，如何表达不同意见？
- 关系与边界：双方是什么关系，哪些话题或行为需要避免？
- 兴趣与长期方向：希望探索什么，如何兼顾陪伴与自我发展？

不要把未发生的事写成真实经历。已有聊天、记忆、性格标签和角色档案也会影响回复。
语言由网页选择器决定，无需在这里强制指定中文或英文。
